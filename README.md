## How I work

- **Testing** — deterministic fixtures, contract tests, an 86-test Telegram agent suite, and multi-version CI.
- **Security** — SSRF defenses, PII redaction, prompt-injection boundaries, CodeQL, and dependency review.
- **Reliability** — timeouts, retries with backoff, concurrency limits, readiness probes, and graceful shutdown.
- **Delivery** — Docker and Compose, GitHub Actions, database-backed CI, and container smoke tests.
